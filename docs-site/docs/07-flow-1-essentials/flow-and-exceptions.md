# Flow and Exceptions

## Key Takeaways

- When an exception goes beyond the brackets, it works its way downward through the flow until the collector is hit.
- The `catch` Flow operator is invoked when there's an uncaught exception coming from upstream.
- Lowkey learning... you can use semicolons in Kotlin to write multiple statements on the same line.

## General Notes

This lesson is about the Flow API, something we barely use in our [Revolver](https://github.com/apegroup/revolver)-based project. I would take a proper look at flows if I were working on another production app. It seems powerful with all these operators.
